# Changelog

Все заметные изменения проекта TaskFlow фиксируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии нумеруются по [Semantic Versioning](https://semver.org/lang/ru/).

## [Unreleased]

## [1.0.0] - 2026-11-19

### Added

- Регистрация пользователей (`POST /users`) и выдача JWT-токена (`POST /tokens`).
- Роли `admin` и `user`, проверка прав доступа на каждом эндпоинте.
- Управление пользователями для администратора: список, блокировка и разблокировка, смена роли.
- Участники проектов (`/projects/{project_id}/members`) и комментарии к задачам (`/tasks/{task_id}/comments`).
- Dockerfile для запуска приложения в контейнере.
- Инструкция по развёртыванию (деплою) в README.md.

### Changed

- Эндпоинты приведены к единому стилю: существительные во множественном числе, именованные параметры пути (`{project_id}`, `{task_id}`).
- Для изменения ресурсов используется `PATCH` вместо `PUT`.

## [0.2.0] - 2026-10-20

### Added

- CRUD для задач: создание, просмотр, изменение и удаление (`/tasks`, `/projects/{project_id}/tasks`).
- Фильтрация задач по статусу, приоритету и исполнителю.
- Поля `status`, `priority`, `assignee_id`, `due_date` в модели задачи.

### Fixed

- Значение статуса задачи по умолчанию заменено с `open` на `todo`.

## [0.1.0] - 2026-10-01

### Added

- Начальная структура проекта: `app/`, `tests/`, `.env.example`, `requirements.txt`.
- Подключение к SQLite через SQLAlchemy, автоматическое создание схемы БД при первом запуске.
- Модели `users` и `projects`.
